## The 60-second version

Signal is a Cala-powered intelligence layer for Swap'n'Serve, a Limerick
clothing-reuse initiative. It treats Cala as a knowledge graph, not a search
box: the full `entity_search → entity_introspection → entity_retrieval`
workflow, typed rows over parsed prose, every fact carrying its provenance and
committed to git so the landscape can be diffed over time. It's static-first by
deliberate design so it costs zero credits to serve and stays inside the free
tier — with one metered live endpoint that degrades honestly.
